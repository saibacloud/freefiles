# freefiles

here u go

## Install

```sh
cp .freefilesrc ~/.freefilesrc
echo '. ~/.freefilesrc' >> ~/.profile
```

## What you get

- One alias
- One editor, `cat`, which reads your file and does not change it
- One color, the one you already had
- `ll`, which shows the first three files in a folder
- A prompt
